# Schriften auf dieser Seite

Alle drei Familien stehen unter der **SIL Open Font License 1.1**. Der
vollständige Lizenztext liegt daneben in [`OFL.txt`](./OFL.txt).

Die OFL erlaubt die kommerzielle Nutzung und das Einbetten in Websites
ausdrücklich. Sie verlangt im Gegenzug, dass Copyright-Vermerk und
Lizenztext mitgeliefert werden — Selbsthosten ist Weitergabe, weil der
Browser die Datei herunterlädt. Genau dafür gibt es diese Datei.

| Familie | Copyright | Herkunft |
|---|---|---|
| **Archivo** | Copyright 2020 The Archivo Project Authors | <https://github.com/Omnibus-Type/Archivo> |
| **Source Serif 4** | © 2014–2021 Adobe Systems Incorporated, with Reserved Font Name „Source" | <https://github.com/adobe-fonts/source-serif> |
| **IBM Plex Mono** | Copyright 2017 IBM Corp. All rights reserved. | <https://github.com/IBM/plex> |

Die Angaben stammen aus den Metadaten der Dateien selbst; alle drei nennen
dort `http://scripts.sil.org/OFL` als Lizenz.

Reserved Font Name ist bei Source Serif der Name „Source". Eine veränderte
Fassung dürfte ihn nicht tragen — hier wird nichts verändert, die Dateien
sind lediglich auf die benötigten Zeichensätze (latin, latin-ext)
zugeschnitten.

## Warum selbst gehostet

Nicht aus Geschwindigkeitsgründen, sondern aus Datenschutzgründen. Wer
Google Fonts vom Google-Server einbindet, überträgt die IP-Adresse jedes
Besuchers in die USA. Das LG München I hat darin 2022 einen Verstoß gegen
das allgemeine Persönlichkeitsrecht gesehen (Az. 3 O 17493/20) und
Schadenersatz zugesprochen — es folgte eine bundesweite Abmahnwelle.

Selbst gehostete Schriften verlassen die eigene Domain nicht. Es wird nichts
an Dritte übertragen, und es braucht keine Einwilligung.
