## Quick Start (5 minutes)

### 1. Download the project

All files are ready in: `/mnt/user-data/outputs/affiliate-intelligence/`

You can:
- Download directly from the outputs folder
- Or clone from GitHub (see next section)

### 2. Install dependencies

```bash
cd affiliate-intelligence
python -m venv venv
source venv/bin/activate
pip install pydantic pyyaml  # Or: pip install -e ".[dev]"
```

### 3. Generate niches

```bash
python main.py
```

### 4. Check output

```bash
cat data/NICHE_GENERATION_REPORT.md
cat data/niches_export.csv
```
